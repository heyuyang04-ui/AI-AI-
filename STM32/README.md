# STM32 board support

`stm32f407zg-pfcllc/` contains the openvela/NuttX board support package for the STM32F407ZG PFC/LLC gateway.

In an openvela/NuttX source tree, map or copy it to:

```text
nuttx/boards/arm/stm32/stm32f407zg-pfcllc/
```

The included `configs/gateway/defconfig` provides the gateway board configuration.
